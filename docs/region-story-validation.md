# 地域群岛与剧情升级验收

日期：2026-09-15。验证分支：`dev`；本次功能基于 `031ce41` 开发，`main` 保持此基线。验收覆盖本次地域群岛与剧情升级，不涉及部署发布。

## 范围与结果

完成六地域、十二群岛簇、六十个稳定岛屿地址、六种岸线轮廓、独立地标调查和可缩放航图。现有港口、前提／结论图形串和证明依赖继续使用原规则。

剧情完成十段主线及八段可选事件，120 个正文段落、六组双选项，另含对应回答与后续回响。中文与英文数据齐全。感情线采用慢热陪伴、心动与同行约定，第二道门之后有独立尾声。

支持跳过、补读、回忆中尝试另一回答、本段回看和断点续读。已揭示的光环裂痕会保留到晚触发的日常事件。选项没有金币、求解有效性或主线门槛的副作用。

## 兼容与后续边界

新建游戏使用新版地域地图。已有存档继续使用原地图，保护现有电路和港口；仍可使用新的剧情阅读器和手记。当前没有把旧进度一键搬到新地形的迁移工具。

本次探索是地图缩放、平移、航图定位和地标调查；没有加入角色行走或操船。六种风貌目前都对应命题逻辑，未来数学分支仅预留数据目录、地理映射、符号适配标识和剧情条件接口。真正引入其他分支仍需相应的解析、图形与验证规则。

完整接入约定参见 `region-story-architecture.md`；已发布地图版本的布局必须冻结，不能直接更改目录／算法并把旧坐标当作新坐标。
