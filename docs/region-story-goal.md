# 开放群岛与奥蕾莉娅剧情 Goal

状态：2026-09-15 已实现并完成验收，纳入 dev 分支；main 基线 031ce41 保持不变。

## 用户确定的方向

- 地域骨架＋群岛簇生成，不使用机械棋盘排列。
- 不同地域有独立的地理风貌，暂不与人物剧情或具体未来数学分支绑定。
- 丰富奥蕾莉娅单女主剧情：慢热陪伴，有心动与约定；第二大关形成阶段性关系成果。
- 为未来 Metamath 多数学分支、地域与人物事件预留数据接口，本次不决定具体分支。
- 影响用户意图的不确定项及时询问。没有推送、发布或修改 main 的授权。

## 交付与验收

1. 稳定、可重现的地域骨架、群岛簇和多样岸线。地域色彩、地表、地标与探索提示可辨识；大地图、岛屿近景和航线互相协调。
2. 保留宽阔连续建造区、真实前提和目标星盘、至少一个可用岸线港口；跨章节或探索顺序不移动岛屿。
3. 地图版本 1 保留已有版本 3 存档的地形和坐标；新游戏使用地图版本 2。数学题目与定理标识保持，不把坐标当作新地域身份。
4. 十章主线有共同探索、日常、分歧、坦白和约定；补充可选相处事件、探索回应及选择回响。中文完整，英文同步。
5. 剧情条件、阅读历史、选项与回忆存档；可以跳过和回顾，不让对话操作影响电路。不用刷好感或强制等待阻塞主线。
6. 地域、风貌、数学内容域、稳定岛屿身份和剧情事件分开定义。新增分支有明确的接入边界和示例。
7. 修正本次相关的交互问题；验证生成空间、港口、存档、剧情条件/选项、章节进展和第一大关回归。
8. 生产构建、静态检查、浏览器实测、真实截图审查通过后才完成 Goal。

## 范围边界

已有数学求解规则不因剧情选项改变。当前地域使用同一命题逻辑内容域；未来分支只保留注册与映射能力，不预制尚未决定的分支内容。此次不引入角色行走、操船、多人、实时生成剧情或后端账户系统。
