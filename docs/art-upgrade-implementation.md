## 最终性能记录

同一机器与 Chromium 148.0.7778.96、1366×768、DPR 1、500 节点、150 可见、50% 缩放；旧版与新版均为生产静态导出，旧基准复用时验证原文件哈希未变。

| 指标 | 旧版 | 新版标准 | 新版轻量 |
| --- | --- | --- | --- |
| rAF 间隔 p50 / p95 | 16.7 / 33.3 ms | 16.7 / 16.8 ms | 16.7 / 16.8 ms |
| wheel 到第二帧回调 | 30.9 ms | 46.6 ms | 17.9 ms |
| 测量区间累计主线程任务时间 | 0.83 s | 1.73 s | 0.017 s |

新版标准档帧间隔更稳定，但绘制成本与本次滚轮响应时间高于旧版；轻量档关闭装饰动画后空闲主线程开销明显降低。rAF 回调不等同于真实屏幕呈现耗时，累计主线程时间不是单帧耗时；不据此承诺跨机器 60fps。JS heap 未强制 GC，不作为保留内存回归结论。真实求解器另行运行五次，最新 p50 10.23 ms、p95 12.85 ms；没有改变求解器。

Headless Chromium 原生日志另记录过 SharedImage 缓冲创建失败及关闭音频管道警告，保存在 artifacts/art-upgrade/chromium-debug.log。页面 JS 与 HTTP 检查均通过，但此环境的采样不能代表实体 GPU 的显示性能。

最终本机预览：http://127.0.0.1:4173/。子路径测试服务完成后已停止；最终 out/ 是根路径版本。
